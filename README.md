# Общий README для репозитория лабораторных работ

## О репозитории

Этот репозиторий содержит комплекс лабораторных работ по дисциплине "Информационные системы и технологии", выполненных в 2025 году. Каждая работа демонстрирует различные аспекты работы с современными информационными технологиями, API популярных платформ и языками программирования.

## Список лабораторных работ

1. **ЛР1**: Технологии создания XML-документов
2. **ЛР2**: Парсинг XML с использованием JavaScript
3. **ЛР3**: Знакомство с VK API
4. **ЛР4**: Работа с API ВКонтакте (Implicit Flow)
5. **ЛР6**: Работа с API ВКонтакте (async/await)
6. **ЛР7**: Создание Telegram бота
7. **ЛР8**: Меню для Telegram бота
8. **ЛР9**: Inline-меню в Telegram
9. **ЛР10**: Трансляция сообщений Telegram→VK
10. **ЛР11**: Telegram бот и XML (курсы валют)

## Технологический стек

- **Языки программирования**: JavaScript, Python, XML, CSS
- **Платформы и API**: Telegram Bot API, VK API, CBR API
- **Библиотеки**: Telegraf, Requests
- **Инструменты**: Git

## Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone https://github.com/{yourusername}/ISIT_labs.git
```

2. Перейдите в нужную директорию лабораторной работы:
```bash
cd ISIT_labs/labX
```

3. Следуйте инструкциям в индивидуальном README работы
