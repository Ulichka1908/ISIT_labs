## Лабораторная работа №1: "Технологии создания XML-документов"

### Подробное описание проекта
Данная лабораторная работа посвящена изучению основ создания валидных XML-документов с соблюдением всех необходимых требований к структуре и вложенности элементов. В рамках работы был разработан тематический XML-документ, содержащий информацию о фильмах, которые пользователь хотел бы посмотреть. Документ включает такие элементы как название фильма, его продолжительность, жанр и рейтинг.

### Детализированная структура проекта
```
lab1/
├── films.xml          # Основной XML-файл, содержащий структурированные данные о фильмах
├── styles.css         # Файл каскадных таблиц стилей для визуального оформления XML-документа
└── README1.md         # Подробное руководство по работе с проектом
```

### Расширенные требования к проекту
1. **Структурные требования**:
   - Минимальная вложенность: 3 уровня
   - Не менее 2 различных элементов второго уровня
   - Не менее 4 различных элементов третьего уровня
   - Для каждого элемента первого уровня - минимум 3 экземпляра
   - Для элементов последующих уровней - минимум 2 экземпляра

2. **Семантические требования**:
   - Логическая структура данных
   - Осмысленные имена элементов и атрибутов
   - Соответствие выбранной тематике

### Подробное руководство по использованию
1. **Просмотр XML-документа**:
   - Откройте файл `films.xml` в любом современном браузере (Chrome, Firefox, Edge)
   - Для корректного отображения убедитесь, что файл `styles.css` находится в той же директории
   - При необходимости можно использовать XML-редакторы (Oxygen XML, XMLSpy) для более детального анализа структуры

2. **Модификация документа**:
   - Для добавления новых фильмов скопируйте и вставьте блок `<movie>...</movie>`
   - Сохраняйте структуру вложенных элементов
   - После изменений обязательно проверяйте валидность документа

### Дополнительные возможности
1. **Расширение функционала**:
   - Добавление атрибутов к элементам (например, год выпуска фильма)
   - Введение новых элементов (например, список актеров)
   - Создание XSD-схемы для валидации структуры

2. **Интеграция с другими технологиями**:
   - Преобразование в JSON с помощью XSLT
   - Использование XPath для поиска по документу
   - Подключение к базам данных с поддержкой XML
