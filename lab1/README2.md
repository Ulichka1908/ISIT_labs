## Лабораторная работа №2: "Парсинг XML с использованием JavaScript"

### Подробное описание проекта
В данной лабораторной работе реализован парсер XML-документов с использованием чистого JavaScript. Проект демонстрирует практическое применение технологий AJAX (XMLHttpRequest) для загрузки и обработки XML-данных в веб-приложении. Основная задача - предоставить пользователю удобный интерфейс для доступа к информации о фильмах из XML-файла.

### Детализированная структура проекта
```
lab1/
├── films.xml          # XML-файл с данными о фильмах
├── parser.js          # JavaScript-код парсера
├── styles_parser.css  # Стили для страницы парсера
├── index.html         # Основная HTML-страница
└── README.md          # Подробное руководство
```

### Расширенный функционал приложения
1. **Основные возможности**:
   - Поиск фильмов по порядковому номеру
   - Вывод полной информации о фильме (название, длительность, жанр, рейтинг)
   - Обработка отрицательных чисел для вывода последних N фильмов
   - Валидация вводимых данных

2. **Дополнительные функции**:
   - Анимация при наведении на элементы
   - Адаптивный дизайн для разных устройств
   - Поддержка темной/светлой темы
   - Локальное хранилище для сохранения последнего запроса

3. **Обработка ошибок**:
   - Проверка на корректность номера
   - Обработка отсутствия фильма с указанным номером
   - Сообщения об ошибках с предложениями по исправлению

### Подробное руководство по использованию
1. **Запуск приложения**:
   - Откройте файл `index.html` в современном браузере
   - Убедитесь, что все файлы (особенно films.xml) находятся в правильных директориях
   - При проблемах с загрузкой XML проверьте консоль разработчика (F12)

2. **Работа с интерфейсом**:
   - Введите положительное число для получения конкретного фильма
   - Введите отрицательное число для получения последних N фильмов
   - Используйте кнопку "Вывести информацию" для выполнения запроса
   - Результаты отобразятся в специальном блоке под кнопкой

3. **Расширенные возможности**:
   - Для разработчиков: модифицируйте parser.js для добавления новых функций
   - Экспериментируйте с CSS для изменения внешнего вида
   - Попробуйте добавить новые поля в XML и адаптировать под них парсер

### Технические детали реализации
1. **Используемые технологии**:
   - XMLHttpRequest для асинхронной загрузки данных
   - DOM API для работы с XML-структурой
   - CSS Grid для макета карточек фильмов
   - Современный JavaScript (ES6+)

2. **Архитектура решения**:
   - Модульная структура кода
   - Разделение логики и представления
   - Обработчики событий для интерактивности
   - Функции для повторного использования кода

3. **Возможности для расширения**:
   - Добавление поиска по названию
   - Фильтрация по жанру или рейтингу
   - Сортировка результатов
   - Пагинация для больших коллекций фильмов
