## Лабораторная работа №11: "Telegram бот и XML"

### Подробное описание проекта
Финансовый бот для Telegram, предоставляющий актуальные курсы валют из официального XML-фида Центробанка РФ. Поддерживает несколько валют, исторические данные и предоставляет удобный интерфейс для работы через inline-кнопки.

### Детализированная структура проекта
```
lab11/
├── bot.py                     # Основной код
└── README11.md                  # Документация
```

### Расширенный функционал системы
1. **Основные функции**:
   - Текущие курсы валют (USD, EUR)
   - Исторические данные за выбранную дату
   - Конвертация сумм
   - Графики изменений

2. **Дополнительные возможности**:
   - Уведомления об изменениях
   - Избранные валюты
   - API для разработчиков
   - Мультиязычность

3. **Особенности реализации**:
   - Работа с XML через SAX-парсер
   - Валидация XSD-схемой
   - Автообновление кэша
   - Фоновая обработка

### Подробное руководство по использованию
1. **Команды бота**:
   ```
   /start - Основное меню
   /usd - Курс доллара
   /eur - Курс евро
   /history - Данные за дату
   ```

2. **Формат даты**:
   - ДД.ММ.ГГГГ
   - Пример: 15.07.2023

3. **Пример запроса**:
   ```
   Пользователь: /usd 23.01.2023
   Бот: Курс USD на 23.01.2023: 68.4567 руб.
   ```

### Технические детали реализации
1. **Схема обработки XML**:
   ```mermaid
   flowchart LR
     A[Запрос ЦБ] --> B{Статус 200?}
     B -->|Да| C[Парсинг XML]
     B -->|Нет| D[Кэш]
     C --> E[Валидация]
     E --> F[Нормализация]
     F --> G[Сохранение]
   ```

2. **Обработка ошибок**:
   - Неверный формат даты
   - Отсутствие данных
   - Проблемы подключения
   - Ограничения API

3. **Производительность**:
   - Время отклика: <800мс
   - Частота обновления: 1 час
   - Глубина истории: 30 дней
