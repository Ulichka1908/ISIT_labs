## Лабораторная работа №3: "Знакомство с VK API"

### Подробное описание проекта
Этот проект представляет собой веб-приложение для работы с API социальной сети ВКонтакте. Основная цель - получение и отображение списка друзей пользователя с дополнительной информацией. Приложение демонстрирует принципы работы с внешними API, обработку JSON-данных и создание динамического пользовательского интерфейса.

### Детализированная структура проекта
```
lab3/
├── meow.html             # Основная страница приложения
└── README3.md             # Полное руководство
```

### Расширенный функционал приложения
1. **Основные возможности**:
   - Получение списка друзей с базовой информацией
   - Фильтрация друзей по городу проживания
   - Отображение сырого JSON-ответа от API
   - Подсчет общего количества друзей

2. **Дополнительные функции**:
   - Сортировка таблицы по различным полям
   - Поиск по имени/фамилии
   - Пагинация для больших списков
   - Кэширование результатов запросов

3. **Особенности реализации**:
   - Использование JSONP для обхода CORS
   - Динамическое создание элементов интерфейса
   - Обработка ошибок API
   - Оптимизация запросов

### Подробное руководство по использованию
1. **Начало работы**:
   - Откройте meow.html в браузере
   - Дождитесь загрузки данных (может потребоваться время)
   - При проблемах проверьте консоль разработчика (F12)

2. **Работа с интерфейсом**:
   - Используйте выпадающий список для фильтрации по городу
   - Наведите на элементы таблицы для подсветки
   - Изучите JSON-ответ в нижней части страницы

3. **Для разработчиков**:
   - Замените access_token на свой в коде
   - Модифицируйте запрос для получения дополнительных полей
   - Добавьте новые функции фильтрации

### Технические детали реализации
1. **Используемые технологии**:
   - VK API версии 5.131
   - JSONP для кросс-доменных запросов
   - Современный JavaScript (ES6+)
   - CSS Flexbox/Grid для макета

2. **Архитектура решения**:
   - Разделение логики и представления
   - Функциональный подход
   - Обработчики событий
   - Динамическое создание DOM-элементов

3. **Возможности для расширения**:
   - Добавление авторизации через VK Connect
   - Поддержка других методов API
   - Визуализация данных (графики, диаграммы)
   - Экспорт данных в CSV/Excel
