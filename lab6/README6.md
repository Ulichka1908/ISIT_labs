## Лабораторная работа №6: "Работа с API ВКонтакте с использованием async/await"

### Подробное описание проекта
Данный проект представляет собой усовершенствованную версию работы с API ВКонтакте, где реализовано асинхронное программирование с использованием современных возможностей JavaScript (async/await). Основная задача приложения - сбор информации о друзьях пользователей, состоящих в определенной группе ВКонтакте, с возможностью ограничения количества обрабатываемых аккаунтов.

### Детализированная структура проекта
```
lab6/
├── lab5.html             # Основная страница приложения
└── README6.md              # Полная документация 
```

### Расширенный функционал приложения
1. **Основные возможности**:
   - Ввод ID группы/встречи и ограничения по количеству аккаунтов
   - Многоэтапный сбор данных (участники группы → друзья участников)
   - Интеллектуальное ограничение запросов для избежания лимитов API
   - Детализированный вывод результатов с иерархической структурой

2. **Дополнительные функции**:
   - Прогресс-бар для отслеживания выполнения запросов
   - Кэширование промежуточных результатов
   - Возможность прерывания длительных операций
   - Экспорт результатов в текстовом формате

3. **Особенности реализации**:
   - Полностью асинхронный код с использованием async/await
   - Обработка ошибок на каждом этапе запросов
   - Оптимизация количества запросов к API
   - Ленивая загрузка данных

### Подробное руководство по использованию
1. **Подготовка к работе**:
   - Откройте lab5.html в современном браузере
   - Убедитесь, что у вас стабильное интернет-соединение

2. **Процесс работы с приложением**:
   - Введите числовой ID группы (или короткое имя) в соответствующее поле
   - Укажите желаемое количество аккаунтов для анализа
   - Нажмите кнопку "Получить список друзей"
   - Наблюдайте за прогрессом выполнения в реальном времени
   - Изучите результаты в виде иерархического списка

3. **Рекомендации по эффективному использованию**:
   - Для больших групп устанавливайте разумные ограничения (50-100)
   - При ошибках попробуйте уменьшить количество запрашиваемых аккаунтов
   - Используйте числовые ID групп для более надежной работы

### Технические детали реализации
1. **Используемые технологии**:
   - VK API methods: groups.getById, groups.getMembers, friends.get, users.get
   - JSONP с динамическими callback-функциями
   - Современный JavaScript (ES2017+)
   - Промисы и async/await для управления асинхронным кодом

2. **Архитектурные решения**:
   - Разделение на сервисный слой, обработку данных и UI
   - Очередь запросов с регулируемым интервалом
   - Мемоизация повторяющихся запросов
   - Изолированные модули с четкими интерфейсами

3. **Оптимизации производительности**:
   - Пакетные запросы пользователей (до 1000 за вызов)
   - Параллельные запросы в пределах лимитов API
   - Предварительная валидация параметров
   - Ленивая загрузка дополнительной информации

4. **Обработка ошибок и исключительных ситуаций**:
   - Автоматический повтор неудачных запросов
   - Гибкая система обработки различных кодов ошибок API
   - Уведомления пользователя о проблемах
   - Сохранение частичных результатов при ошибках
