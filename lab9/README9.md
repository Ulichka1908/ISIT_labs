## Лабораторная работа №9: "Создание inline-меню"

### Подробное описание проекта
Данный проект реализует Telegram-бота с интерактивным inline-меню, позволяющим пользователям оценивать контент с помощью реакций "Нравится/Не нравится". Система автоматически подсчитывает и отображает количество голосов в реальном времени, демонстрируя работу callback-запросов и динамическое обновление интерфейса.

### Детализированная структура проекта
```
lab9/
├── lab9.py                       # Основной код
└── README9.md                    # Полная документация
```

### Расширенный функционал системы
1. **Интерактивное голосование**:
   - Inline-кнопки с мгновенным обновлением счетчиков
   - Визуальная индикация выбора

### Подробное руководство по использованию
1. **Команды управления**:
   - `/start` - создать новый опрос
   - `/stats` - просмотр детальной статистики

2. **Работа с inline-меню**:
   - Нажмите кнопку "Нравится" или "Не нравится"
   - Наблюдайте обновление счетчика в реальном времени

### Технические детали реализации
1. **Стек технологий**:
   - Telegraf
   - InlineKeyboardMarkup
   - Пакетная обработка callback-запросов
